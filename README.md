# 基于react开发的在线视频编辑器

该项目使用 [Create React App](https://github.com/facebook/create-react-app).

## 项目说明
本项目目前实现了大致的界面，支持的功能包括：
- 选中“我的资源”侧边栏，点击资源区的“本地上传”可以上传本地的视频，在“项目素材”栏下可以选中视频，让右侧的播放区域播发选中的视频
- 点击“项目素材”视频右上方的“+”可以将视频添加到轨道上面
- 当轨道上面有视频素材时，可以修改视频播放区域下方的帧滑轮修改时间轴上每帧的宽度。帧滑轮左右两边的按钮也能实现同样的效果
- 右击轨道上面的素材，会出现下拉栏。其中的“删除”选项可以将素材删除

## 配置和运行
- 1、如果是第一次运行，需要：
  - 1\) `npm i -g pnpm`
  - 2\) `pnpm install ` 
- 2、开发环境运行 `npm start`
- 3、生产环境运行 `npm build`
